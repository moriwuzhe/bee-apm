### 9. API 功能
#### Dashboard APIs
- `GET /api/dashboard/stats` - 统计数据
- `GET /api/dashboard/trend` - 趋势数据
- `GET /api/dashboard/alert-trend` - 告警趋势
- `GET /api/dashboard/recent-alerts` - 最近告警
- `GET /api/dashboard/top-apps` - Top应用

#### Project APIs
- `GET /api/projects` - 获取项目列表
- `GET /api/projects/{id}` - 获取项目详情
- `GET /api/projects/env/{env}` - 按环境获取项目
- `POST /api/projects` - 创建项目
- `PUT /api/projects/{id}` - 更新项目
- `DELETE /api/projects/{id}` - 删除项目
- `GET /api/projects/search?keyword=` - 搜索项目

#### Application APIs
- `GET /api/applications` - 获取应用列表
- `GET /api/applications/{id}` - 获取应用详情
- `GET /api/applications/project/{projectId}` - 按项目获取
- `GET /api/applications/status/{status}` - 按状态获取
- `POST /api/applications` - 创建应用
- `PUT /api/applications/{id}` - 更新应用
- `DELETE /api/applications/{id}` - 删除应用
- `GET /api/applications/search?keyword=` - 搜索应用

#### User APIs
- `GET /api/users` - 获取用户列表
- `GET /api/users/{id}` - 获取用户详情
- `POST /api/users` - 创建用户
- `PUT /api/users/{id}` - 更新用户
- `DELETE /api/users/{id}` - 删除用户
- `GET /api/users/search?keyword=` - 搜索用户

#### Role APIs
- `GET /api/roles` - 获取角色列表
- `GET /api/roles/{id}` - 获取角色详情
- `POST /api/roles` - 创建角色
- `PUT /api/roles/{id}` - 更新角色
- `DELETE /api/roles/{id}` - 删除角色

#### Release APIs
- `GET /api/releases` - 获取发布列表
- `GET /api/releases/{id}` - 获取发布详情
- `GET /api/releases/app/{appName}` - 按应用获取
- `POST /api/releases` - 创建发布
- `PUT /api/releases/{id}` - 更新发布
- `DELETE /api/releases/{id}` - 删除发布

#### JVM Monitor APIs
- `GET /api/jvm/applications` - 获取应用列表
- `GET /api/jvm/host-metrics?appName=` - 主机指标
- `GET /api/jvm/heap-mem` - 堆内存
- `GET /api/jvm/threads` - 线程
- `GET /api/jvm/gc` - GC
- `GET /api/jvm/network` - 网络
- `GET /api/jvm/class-loading` - 类加载

#### DataSource APIs
- `POST /api/datasource/switch/{type}` - 切换数据源
- `GET /api/datasource/current` - 当前数据源
- `GET /api/datasource/list` - 数据源列表

## 🚀 运行方式

### 启动后端服务
```bash
cd apm-ui/backend
mvn spring-boot:run
```

后端将在 http://localhost:8081 运行

### 测试API
打开 `apm-ui/test-api.html` 即可测试所有 API

### 访问API文档
http://localhost:8081/api
